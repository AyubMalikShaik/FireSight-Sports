# Architecture Overview

## FireSight Sports System Architecture

- **Frontend (`frontend/firetv-app`)**: FireTV app client.
- **Backend (`backend/api`)**: API services for match data, live streams, and application state.
- **Computer Vision (`cv/gesture-service`)**: Computer vision service handling gesture recognition.
- **Database (`database/`)**: SQL schema and seed data.
- **Data (`data/`)**: Sample match data and mock resources.
